# Definiciones de métricas

| Métrica | Fórmula |
|---|---|
| Tasa de calificación | leads `qualified` / leads detectados (período) |
| Tasa de contacto | oportunidades que alcanzaron "Contactado" / leads calificados |
| Tasa de reunión | alcanzaron "Reunión programada" / contactados |
| Tasa de propuesta | alcanzaron "Propuesta enviada" / reuniones |
| Win rate | ganadas / (ganadas + perdidas) cerradas en el período |
| Tiempo medio de cierre | promedio (won_at − created_at) de ganadas |
| Valor de pipeline | suma de `estimated_value` de oportunidades abiertas, por moneda |
| Costo de adquisición (CAC) | costos de captación aprobados del período / clientes ganados. Requiere registrar costos; si no existen, no se calcula |
| Rendimiento por fuente | ganadas e ingresos por `source` del lead de origen |
